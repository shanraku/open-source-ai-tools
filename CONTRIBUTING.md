# Contributing

Thanks for helping make this directory more useful.

## Before contributing

- Search the current directory to avoid duplicate entries.
- Prefer the tool's official website and official pricing page.
- Write a neutral, factual description. Avoid unsupported superlatives.
- Check the category and access label against the project's allowed values.
- Never include secrets, private user data or copied marketing content.

## Suggest a tool

Open a [Tool submission issue](https://github.com/shanraku/open-source-ai-tools/issues/new?template=tool_submission.yml) and provide the official URL, category, pricing model and a short description.

## Pull requests

1. Fork the repository and create a focused branch.
2. Make the smallest useful change.
3. Test search, category filters, pricing filters and sorting in a browser.
4. Check the page at a narrow mobile width and a desktop width.
5. Open a pull request describing what changed and how it was tested.

## Maintainer review

Submissions may be edited or declined if information cannot be verified, the link is unsafe, the entry is a duplicate, or the submission violates the project's guidelines.
